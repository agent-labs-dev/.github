# Agent Labs community defaults

This repository holds the community health files that every public [Agent Labs](https://github.com/agent-labs-dev) repository uses when it has no copy of its own: the contributing guide, code of conduct, security policy, issue forms and pull request template.

A repository overrides any one of them by committing its own file of the same name. GitHub then uses the repository's copy for that file and these defaults for the rest. An issue form folder in a repository replaces all of the default forms, including `config.yml`.

See [GitHub's documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
